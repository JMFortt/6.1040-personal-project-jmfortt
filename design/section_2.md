# Section 2: Application Pitch

## The Name

I chose the name TAble for this application (since the goal is to replace the many Google Sheets used most frequently by TAs).

## Motivation

This application will solve the problem of shift scheduling, attendance tracking, and schedule maintenance for course staff in large college courses.

## Key Features

Shared Scheduling: You can manually create schedules in the app once so everyone can see the same up-to-date version (No more checking different spreadsheets to do different things with the same schedule!).

Attendance Tracking: You can make users able to mark attendance on the schedule or able to just view the attendance records based on role permissions (so one can verify that they've been marked present during a shift!).

Schedule Maintenance: You can have schedule changes, schedule swaps, covers, etc. all handled on the site (so everyone has one source of ground truth regardless of changes made!).
